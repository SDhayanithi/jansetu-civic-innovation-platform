# JanSetu — Civic Innovation Platform

**JanSetu** connects citizens, government departments, universities, and industry to identify societal challenges, develop innovative solutions, and track their journey from problem to verified implementation across Jharkhand's 24 districts.

## 🚀 Live Website
- **GitHub Pages:** [https://sdhayanithi.github.io/jansetu-civic-innovation-platform/](https://sdhayanithi.github.io/jansetu-civic-innovation-platform/)

## ✨ Key Platform Features
- **Grassroots Problem Reporting:** Geotagged problem submissions with photo/evidence upload and community context.
- **AI Intelligence & Duplicate Detection:** Automatic category classification, severity scoring, SDG alignment, and duplicate detection.
- **Interactive GIS Map:** Real-time problem and solution visualizer across all districts.
- **Collaborative Ecosystem:** Multi-stakeholder portals for Citizens, Government Departments, Universities/Researchers, and Industry Partners.
- **Bilingual Interface:** Full Hindi and English localization support.
- **Milestone & Impact Tracking:** Transparent accountability from civic submission to piloted implementation.

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Routing:** TanStack Router (Client-side SPA with base path support)
- **State Management & Querying:** TanStack React Query
- **Styling:** Tailwind CSS + Radix UI Primitives + Lucide Icons
- **Mapping:** Leaflet & OpenStreetMap
- **Charts:** Recharts
- **Hosting:** GitHub Pages with GitHub Actions CI/CD

## 💻 Local Development

```sh
# Clone repository
git clone https://github.com/SDhayanithi/jansetu-civic-innovation-platform.git
cd jansetu-civic-innovation-platform

# Install dependencies
npm install

# Run development server
npm run dev

# Run production build
npm run build
```
